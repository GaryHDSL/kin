# Core Webber Website Assets

Upload website images and logos into this folder.

Suggested folders:
- `logo/` — company logos and favicon files
- `properties/` — property listing photos
- `renovations/` — renovation project photos
- `construction/` — construction project photos
- `plumbing/` — plumbing service photos
- `painting/` — painting service photos
- `electrical/` — electrical service photos

To add a folder, upload a file using a path such as `assets/properties/house-1.jpg`.
